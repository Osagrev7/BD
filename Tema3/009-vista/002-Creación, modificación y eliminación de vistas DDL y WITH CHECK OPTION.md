Las vistas se gestionan mediante instrucciones DDL, es decir, el lenguaje de definición de datos. 

| Comando         | Acción                        |
| --------------- | ----------------------------- |
| **CREATE VIEW** | Crear una vista nueva         |
| **ALTER VIEW**  | Modificar una vista existente |
| **DROP VIEW**   | Borrar la vista del sistema   |

Además, `WITH CHECK OPTION` sirve para controlar que modificaciones se permiten a través de una vista.
